OVERLEAF INSTRUCTIONS

1. In Overleaf choose New Project > Upload Project.
2. Upload MLWA_Final_TopClass_Overleaf.zip.
3. Set the main document to main.tex.
4. Use pdfLaTeX as the compiler.
5. To compile the supplement, temporarily set the main document to
   supplementary_material.tex, then switch back to main.tex.

Do not rename or move the figures/, tables/, or supplementary/ folders because
the LaTeX paths depend on them.

# Submission hygiene checklist

Before journal submission, verify that the final PDF does not contain any of these strings:

- `email.to.be.added@example.com`
- `YOUR_USERNAME`
- `zenodo.XXXXXXX`
- `to be added`
- `should be inserted`
- `before submission`
- `placeholder`

Required final items:

- Real corresponding-author email.
- Public GitHub repository link.
- Zenodo or OSF DOI.
- Final README with run steps.
- Environment file.
- Final CSV result tables.
- Final figures.
- Notebook/code used for the paper results.
- License and citation files.
